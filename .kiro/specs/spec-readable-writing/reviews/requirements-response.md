## サイクル1 往復1 への対応(2026-10-02)

この往復の修正で、要件を1つ足したため、要件の番号が変わった。旧要件3〜6は、新しい番号では要件4〜7になる。

| ID | 処置 | 内容 |
|---|---|---|
| R1-1-1 | 修正 | 要件2に受入基準7を足した。design.md の「対応する要件」の行と、tasks.md でタスクと要件の対応を示す行は、要件の番号だけで書くと定めた。受入基準6は、文の中で別の要件に触れるときに限る書き方に直した |
| R1-1-2 | 修正 | 要件5(旧要件4)に受入基準3を足した。tasks.md で、受入基準とそれを確かめるテストの対応を示すために受入基準を引くことは、書き写しに当たらないと定めた |
| R1-1-3 | 修正 | 要件2の受入基準2に例外を足した。「ラベル: 内容」の形の箇条書きでは、ラベルが主語や条件を示すので、内容の文で主語を省いてよいと定めた |
| R1-1-4 | 修正 | 要件3「文書の組み立て」を新しく足した。requirements.md の各要件の組み立て(見出し、理由の段落、番号付きの項目。利用者の立場を名乗る行と「受入基準」の小見出しは書かない)と、design.md の部品の節の組み立て(見出し、対応する要件の行、日本語の欄)を定めた。tasks.md には見本が無いので、この spec の design.md に見本を載せ、所有者が design を承認したらそれを基準にすると定めた。要件6(旧要件5)の受入基準1の点検の対象に、文書の組み立てを含めた |
| R1-1-5 | 記録のみ | 低。この文書の「範囲」と要件1の受入基準2が、同じ決めごとを書いている。表現の重なりで、要件の中身には影響しない |
| R1-1-6 | 記録のみ | 低。spec を審査するときに従う決まりが、雛形の英語の節名を参照している。雛形を変えるときに審査の決まりをどう合わせるかは、design で扱う |
