### 申告

**1. 書き換えを防ぐ範囲を、Claude が実行するすべてのコマンド(サブエージェントを含む)にした** — 要件1の2と3

- Issue の記載: あり。「Claude がこの書き換えを起こさないことを、メモリに頼らず仕組みで防ぐ(AIの提案を了承)」。きっかけと困っていることは、起票の題名(`gh issue create --title`)の例だけである
- 決めたこと: コマンドの種類を問わず、Claude と、Claude が作業を任せたサブエージェントが実行するすべてのコマンドを対象にした
- 他にありえた選択肢: 記録に残る引数を扱うコマンド(`gh issue create` `gh pr create` `gh issue comment` など)だけを対象にする。`/` で始まる文字列を引数に書くときの書き方(ファイル渡し)を手順に固定し、コマンド全般には手を入れない
- 外れていた場合: 範囲が広いので、今まで Git Bash の書き換えに頼って動いていたコマンドがあれば影響を受ける(要件2が縛るのは列挙したコマンドとフックだけである。指摘 R1-1-1 を参照)。逆に範囲を狭めると、起票以外のコマンド(コミットメッセージを `-m` で渡す、`gh pr edit --title` など)で再発する

**2. 作業PCごとの設定を要らなくし、リポジトリの内容だけで防ぐことにした** — 要件3

- Issue の記載: あり。「メモリに頼らず仕組みで防ぐ」。作業PCごとの設定の可否は書かれていない
- 決めたこと: 所有者と参加者は、変更を取り込んだリポジトリで Claude を使うだけで防げる。作業PCごとの設定も、Git for Windows 以外のプログラムの追加も要らない
- 他にありえた選択肢: `keirekipro.parallelSlots` と同じように、作業PCごとに一度だけ行う設定(`git config` や環境変数)を参加者セットアップの手順書に書く。Git for Windows の設定(`MSYS` 環境変数をシステムに置く)を手順にする
- 外れていた場合: リポジトリの内容だけで防ぐ手段は、Claude が実行するすべてのコマンドの環境に効く置き場所(`.claude/settings.json` やフック)に限られ、どれもゲート設定なので所有者の承認と手置きが要る。作業PCごとの設定にすると、設定を忘れた作業PCで再発し、Issue の「メモリに頼らず」の趣旨から外れる

**3. 防ぐ手段が働いているかを確かめる自動のテストを要件にした** — 要件4

- Issue の記載: なし
- 決めたこと: 防ぐ手段には自動のテストがあり、手段を外すか壊す変更をするとテストが失敗する
- 他にありえた選択肢: テストを作らず、設定の存在を参加者セットアップの手順書や週次監査で確かめる。起票と PR 作成のあとに題名を読み直す確認(メモリに書いてある手順)を `/ship` と `file-issue` の手順に書く
- 外れていた場合: テストを作る分だけ作るものが増える。テストをどこで流すか(ホストの Git Bash か、コンテナや CI の Linux か)で、確かめられる範囲が変わる(指摘 R1-1-4 を参照)

**4. 実行の前に止められたときは、理由と実行できる書き方を Claude に伝えることにした** — 要件1の5

- Issue の記載: なし
- 決めたこと: 書き換えを防ぐためにコマンドが実行の前に止められたら、止められた理由と、止められずに実行できる書き方が Claude に伝わり、Claude は書き直して実行できる
- 他にありえた選択肢: 止めずに書き換えだけを起こさなくする(止める場面を作らない)。止めるだけで、書き方は案内しない
- 外れていた場合: 止める方式を design が選ぶかどうかは、この項目だけでは決まらない。止めない方式を選ぶとこの項目は使われない。止める方式を選ぶと、要件1の1の「書いたとおりの文字で届く」と噛み合わない(指摘 R1-1-2 を参照)

**5. 所有者が自分の端末で打つコマンドと、CI で動くコマンドを範囲外にした** — 範囲の節

- Issue の記載: あり。困っていることもやりたいことも Claude が実行するコマンドだけを指している
- 決めたこと: 所有者が自分の端末で打つコマンドと CI(Linux)は決めない
- 他にありえた選択肢: 所有者の端末で打つコマンド(`start-dev.sh` のように所有者が打つスクリプトを含む)も同じ仕組みで覆う
- 外れていた場合: 所有者が自分の端末で `/` で始まる文字列を引数に打ったときの書き換えは、この spec では防がれない。影響は所有者の操作に限られ、Claude の作業には及ばない
