# 所有者が差し戻した文の一覧

このファイルには、所有者がこれまでに「意味が分からない」「わかりにくい」と差し戻した文と、Claude がその文を書き直した文を、組にして並べる。Claude は、書き方の決まりを変えたときに、この一覧を使って、決まりが差し戻された文を見つけられるかと、書き直した文を誤って外れたと判断しないかを確かめる。

組の見出しには、組の番号と出どころを書く。出どころは、次の3つのどれかである。

- spec のファイル名: そのファイルに、差し戻された文が今も残っている
- 会話の日付: Claude Code の会話の記録のうち、その日に Claude が差し戻された文を書いた記録がある。日付は、会話の記録に残る時刻を協定世界時で読んだ日付である
- メモリのファイル名: 所有者の PC の Claude Code のメモリのファイルに、差し戻された文が書き残されている

差し戻された文は、出どころに残っている文をそのまま写す。前後の文も、差し戻された文を読むのに要る範囲で写す。写した範囲の途中を省いたところには「(中略)」と書く。
