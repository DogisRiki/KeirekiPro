# memory-inspect-now

Claude は、このスキルで、メモリの点検をその場で1回動かし、終わった点検の報告を示す。
報告を示したあとに、開発者が直しを戻すよう頼んだときや、案に答えたときは、Claude はスキル `memory-inspection` に従う。

## 手順

1. Claude は、作業フォルダの最上位で `bash .claude/scripts/memory/memory-inspect.sh run-now` を、Bash の道具の `run_in_background` で動かす。点検は60分まで続くことがあるので、Claude は点検の終わりを待たずに返事を返す。開発者は、点検の間も会話を続けられる
2. Claude は、点検を始めたことと、点検が終わったらこの会話で報告を示すことを、開発者への返事に書く
3. 点検のコマンドが終わったら、Claude は、終了コードで次のとおりにする
   - 終了コード 0 か 1: Claude は、出力の1行目の回の ID で、スキル `memory-inspection` の「報告を示す」の手順のとおりに報告を示す。終了コード 1 は中断した回で、報告には中断の理由が載る。出力に `[memory-inspection] finished:` の行が無いときは、点検が始まる前に止まったので、Claude は「それ以外」と同じにする
   - 終了コード 3: Claude は、点検がすでに動いているので2つ目の点検を動かさなかったことを、開発者への返事に書く。動いている点検の報告は、その点検を動かした会話の Claude が点検の終わったあとに示すか、次の会話の Claude が会話の始めに示す
   - それ以外: Claude は、出力の終わりの部分と、点検を動かせなかったことを、開発者への返事に書く
4. 点検の途中で会話が閉じられると、点検はそこで止まる。止まった回は、次の点検か次の会話の始めに中断として扱われ、次の会話の Claude が、会話の始めにその回の報告を示す
